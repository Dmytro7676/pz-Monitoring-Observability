1.	pz-MQTT — MQTT Broker
Практична робота з MQTT-протоколом.
MQTT — легкий мережевий протокол для:
•	IoT 
•	сенсорів 
•	smart home 
•	publish/subscribe архітектури

Як запускати
Перехід
cd C:\Users\dmytr\pz-MQTT\broker

Запуск контейнера
docker compose up -d

Перевірка
docker ps

Publish / Subscribe demo
Subscriber
docker exec -it mqtt-broker sh
mosquitto_sub -h localhost -t test/topic

Publisher
Інше вікно:
docker exec -it mqtt-broker sh
mosquitto_pub -h localhost -t test/topic -m "Hello MQTT"

Результат
Hello MQTT

5. pz-SOLID

Що це
Практична робота по SOLID-принципах.

Для чого SOLID
SOLID:
•	покращує архітектуру 
•	зменшує зв’язність 
•	спрощує підтримку 

Принципи

S — Single Responsibility
Одна відповідальність.

O — Open/Closed
Відкритий для розширення,
закритий для змін.

L — Liskov
Похідний клас має заміняти базовий.

I — Interface Segregation
Малі інтерфейси краще за великі.

D — Dependency Inversion
Залежність від абстракцій.

Як запускати
Перехід
cd C:\Users\dmytr\pz-SOLID

Встановлення залежностей
npm install

Запуск тестів
npm test

Що показати
PASS

Було виконано рефакторинг коду із застосуванням принципів SOLID та розділенням відповідальностей між компонентами системи.
